Sincronizzazione

Ogni modifica si salva subito sul dispositivo e, dopo un paio di secondi, nel tuo repository GitHub privato. Così ritrovi tutto su PC e telefono.

Come creare il token
  1. Apri GitHub → nuovo token fine-grained.
  2. Nome Archivio, scadenza a scelta.
  3. Repository access → Only select repositories → lavoro-dati.
  4. Permissions → Contents → Read and write.
  5. Generate token, copialo e incollalo qui sopra.

Collega il telefono

Con il PC già collegato, inquadra il codice con la fotocamera del telefono. Poi dal browser scegli “Aggiungi a schermata Home”.

Il codice contiene il tuo token: non mostrarlo ad altri.
