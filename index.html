    Impostazioni

    Sincronizzazione con GitHub

    I contenuti vengono salvati subito su questo dispositivo e, pochi secondi dopo, nel repository privato indicato qui sotto. Così sono visibili sia dal PC che dal telefono.

    Come creare il token (una volta sola)
    1. Apri github.com → Fine-grained token.
    2. Nome: Archivio. Scadenza: quella che preferisci.
    3. Repository access → Only select repositories → scegli il repository dati.
    4. Permissions → Contents → Read and write.
    5. Premi Generate token, copialo e incollalo qui sopra.

    Collega il telefono

    Dopo aver collegato il PC, inquadra il codice QR con la fotocamera del telefono: il telefono verrà configurato in automatico. Poi, dal browser, usa “Aggiungi a schermata Home”.

    Il QR contiene il tuo token: non condividerlo con nessuno.
